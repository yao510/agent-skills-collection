# Agent Skills Collection

> 16 个生产可用的 AI Agent 技能, 覆盖学术投稿自动化 / 鸿蒙开发 / 视频处理 / 代码与 Agent 方法论。
> 兼容 Claude Code, Cursor, Cline, Gemini CLI, GitHub Copilot 等支持 SKILL.md 的 agent (skills.sh 生态)。

## 安装
```bash
npx -y skills add REPO_OWNER_PLACEHOLDER/agent-skills-collection
# 或指定单个技能:
npx -y skills add REPO_OWNER_PLACEHOLDER/agent-skills-collection --skill <name>
```
