# 备案表单逐字段填写指南

## AGC应用创建

### 进入路径
AGC控制台 → 「我的项目」→ 选择项目 → 「添加应用」

### 关键字段

| 字段 | 正确填法 | 常见错误 |
|------|---------|---------|
| 选择平台 | **APP(HarmonyOS)** | 选成Android ❌ |
| 支持设备 | 手机（或手机+平板） | |
| 应用名称 | 与备案名称一致 | 备案写A、AGC写B ❌ |
| 应用包名 | 7~128字符，如 `com.hanzi.learn` | 用默认的 `com.example.xxx` 不够专业；创建后不可改 |
| 应用分类 | 「应用」 | 选「游戏」会触发实名认证/防沉迷要求 ❌ |
| 默认语言 | 简体中文 | |

### 包名命名建议
- 格式: `com.或cn.域名倒写.项目名`
- 示例: `com.hanzi.learn`、`cn.company.appname`
- 不要用 `com.example.xxx`（DevEco默认值，不专业）
- 一旦创建无法更改，提前确定

## 备案表单: 互联网信息页

### 1. 互联网信息服务类型
- 选 **APP**
- 五个选项区别:
  - 网站: 有域名的Web站点
  - **APP**: 手机原生应用（选这个）
  - 元服务: 华为元服务（轻量免安装）
  - 快应用: 华为快应用
  - 快游戏: 华为快游戏

### 2. APP名称
- 与AGC应用名称完全一致
- 不要含「游戏」字样（可能被要求游戏类资质）

### 3. 首页地址
- 纯APP备案: 留空
- 如果有官网: 填官网URL
- 没有域名时不是必填

### 4. 服务内容/类别
- **个人开发者强烈推荐选「其他」**（2026-07 实测：选「教育」会被要求提供《教育相关资质证件》，个人无法提供 → 直接驳回）
- 如确实有办学/教育培训资质: 可选「教育」，但需上传资质扫描件
- **绝对不要选「游戏」**: 需要游戏版号等复杂资质
- 如果选了「教育」被驳: 回到本页改选「其他」重新提交即可

### 5. 服务类型
- 选 APP

### 6. 语言
- 选实际支持的语言
- 只有中文界面: 选「中文(简体)」
- 有英文界面: 加选「英语」
- 多选不影响审核

### 7. 备注（必填，⚠️ 高频驳回项）

**2026-07 华为云初审明确要求：备注栏必须包含标准承诺话术，否则直接驳回。**

填写结构 = **功能描述 + 承诺话术模板**（两部分缺一不可）

**第1部分 — 功能描述**：
- 写清用途+具体功能，控制在20字以内
- 用「学习辅助工具」「练习」「本地离线」「休闲应用」等词
- **避开**：「平台」「社区」「在线课程」「社交」「金融」「企业」「单位」等超个人范围的词

**第2部分 — 承诺话术模板（必须原样包含，不可删减）**：

```
（APP主要用于[替换为你的功能描述]，本APP是个人使用APP，不含有企业、单位等个人信息，若在核实APP中含有企业、单位等信息、本人愿意以虚假数据信息进行备案，下架APP、并将主体和域名加入黑名单的处罚。）
```

**完整示例（汉字学习类）**:
```
（APP主要用于汉字书写笔画学习与练习，本APP是个人使用APP，不含有企业、单位等个人信息，若在核实APP中含有企业、单位等信息、本人愿意以虚假数据信息进行备案，下架APP、并将主体和域名加入黑名单的处罚。）
```

**完整示例（休闲游戏类）**:
```
（APP主要用于休闲割草类单机游戏娱乐，本APP是个人使用APP，不含有企业、单位等个人信息，若在核实APP中含有企业、单位等信息、本人愿意以虚假数据信息进行备案，下架APP、并将主体和域名加入黑名单的处罚。）
```

> ⚠️ 模板中的括号 `（）` 是中文全角括号，照抄。中间的 `[替换为你的功能描述]` 替换为实际内容后删除方括号。

### 8. APP图标文件
- 格式: PNG/JPG/JPEG
- 大小限制: ≤100KB
- 建议尺寸: 256x256 或 512x512
- 如果原图太大: 用Python PIL压缩
```python
from PIL import Image
img = Image.open('icon.png')
img.resize((256, 256), Image.LANCZOS).save('icon_256.png', 'PNG', optimize=True)
```

### 9. 是否提供SDK服务
- 一般选 **否**

### 10. 是否应用SDK服务
- 一般选 **否**
- 如果集成了华为分析/推送等SDK: 可选「是」，但选「否」通常不会被查

## 备案表单: 接入及平台信息

### 1. 资源类型
- 选 **备案授权码**
- 其他选项（ECS/Flexus等）需要服务器直接在该云上

### 2. 备案授权码
- 粘贴从华为云备案系统生成的授权码

### 3. 域名信息
- 没有域名: **直接填ECS公网IP地址**
- 有域名: 填域名URL
- 一行一个，不要空行
- ⚠️ **必须与 ECS 实际绑定 IP 完全一致**（2026-07 驳回原因 #6：填错IP或IP已变更 → 直接驳回）

### 4. 关联的IP地址
- IP: **填ECS实际公网IP（与域名信息完全相同）**
- 域名: 填同一个IP或域名
- ⚠️ 提交前务必去 ECS 控制台核对当前绑定的公网IP，确保三处一致：授权码对应IP = 域名字段IP = 关联IP字段

### 5. 平台选择（关键！）
- **只勾「鸿蒙」**
- 取消其他所有平台（安卓/iOS/黑莓/Linux）
- 多选其他平台会被要求提供对应平台的截图/证明

### 6. 运行平台信息
| 字段 | 填法 |
|------|------|
| 运行平台 | 鸿蒙 |
| 运行平台类型 | 移动智能终端 |
| 域名 | 下拉选已填的IP/域名 |

### 7. APP包名/公钥/签名MD5

| 字段 | 来源 | 是否必填 |
|------|------|---------|
| 鸿蒙包名 | AGC应用详情页复制 | 必填 |
| 公钥 | AGC签名证书详情 | 部分省份不强制 |
| 签名MD5值 | AGC签名证书详情 | 部分省份不强制 |

**策略**: 先填包名、留空公钥和MD5，直接提交试试。如果被拒再补。

**获取公钥和MD5的途径**:
1. AGC → 「证书、APP ID和Profile」→ 查看已创建的证书详情
2. DevEco Studio → File → Project Structure → Signing Configs
3. 命令行从.p12文件提取（需要密码）:
```bash
# 导出证书
openssl pkcs12 -in app.p12 -clcerts -nokeys -out cert.pem -passin pass:你的密码
# 获取MD5指纹
openssl x509 -in cert.pem -noout -fingerprint -md5
# 获取公钥
openssl x509 -in cert.pem -noout -pubkey
```

## 备案表单: 上传资料

通常需要上传:
1. 负责人证件照（身份证正反面）
2. 手持证件照（部分省份）
3. 签署《真实性核验承诺书》
4. 可能需要人脸识别验证

---

## 备案提交后

- 状态: 等待初审 → 等待管局审核 → 通过
- 时间: 初审1-3工作日 + 管局审核约20工作日
- 通过后: 收到短信/邮件，获得备案号（如 `沪ICP备XXXXXXXX号`）
- 在AGC填入备案号完成核准
