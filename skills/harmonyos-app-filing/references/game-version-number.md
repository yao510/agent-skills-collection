# 游戏版号（ISBN）申请指引

> 适用：鸿蒙/各平台**游戏类**应用上架国内商店。非游戏类（工具/教育）一般不需要版号。

## 核心结论

- **游戏版号 =《网络游戏出版物号》(ISBN)**，国家新闻出版署核发。国内游戏上线运营（含免费提供下载）**原则上必须版号**，否则非法运营（下架/罚款/刑责）。
- **个人无法申请版号**——主体必须是**内资企业（有限责任公司）**，且需《电信与信息服务业务经营许可证》(ICP证) + 软件著作权(软著)。
- 纯单机、无联网、无内购、无广告的休闲游戏，**法规层面理论上可免版号**，但应用商店（尤其华为）对"游戏"分类审核严，上架时可能仍被要求版号。

## 三条路线（先拍板）

| 路线 | 做法 | 周期 | 成本 | 风险 |
|------|------|------|------|------|
| A 正规版号 | 注册公司+软著+ICP证+出版社申报 | 6-12月 | 数万元 | 最低，合规 |
| B 规避 | 商店走"应用"分类，声明单机 | 即时 | 0 | 有被打回/下架风险 |
| C 联合出版 | 找有版号出版公司联合运营(分成) | 1-3月 | 分成 | 让渡权益 |

## 路线A 前置与流程

**前置（按顺序）**：
1. 注册内资公司（经营范围含软件开发/网络文化），3-7工作日
2. 软著登记（中国版权保护中心），1-2月
3. ICP经营许可证（省通信管理局，需注册资本≥100万+3名社保），2-3月
4. 找有网络出版服务许可证的出版社做审读（申报必经通道）

**流程**：软著 → ICP证 → 出版社审读(1-2月) → 省新闻出版局受理(5-10工作日) → 国家新闻出版署审批(2-6月，含专家评审+公示) → 核发ISBN号

**必备材料**：软著证、ICP证、营业执照、出版社审读报告、游戏包体+测试账号(含未成年人模式)、说明书/脚本/氪金点说明、内容合规自查报告

**周期费用(2025-2026参考)**：手游总周期4-8月(不含前置再加4-6月)；国家不收费，实际花费(代理+注册)约2-5万元

## 关键注意

- 版号与**版本绑定**：改名/大幅更新需重新审批，仅修BUG免审
- 版号与**主体绑定**：不可转让
- 拿号前技术测试须小范围(≤1万人)、不计费、删档、不公开宣传、向省级出版部门报备
- 内容审查：暴力/血腥/赌博/篡改历史/违背核心价值观会驳回

## 个人开发者建议

先用路线B快速上架验证市场 → 同时注册公司+启动软著铺路 → 数据好再补版号转正规。别一上来砸几万办版号。
