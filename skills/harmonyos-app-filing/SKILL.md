# HarmonyOS APP 备案与上架全流程

## Overview

本技能基于实际走通的鸿蒙APP备案经验提炼，覆盖从「备案前决策」到「拿到备案号回填AGC」的完整链路。核心价值在于：避坑指南和官方链接，减少反复试错。

备案涉及两个独立系统：
- **华为云备案系统** (console.huaweicloud.com/beian) — 提交备案申请
- **AppGallery Connect / AGC** (developer.huawei.com) — 应用管理与上架

## 工作流决策树

```
用户需要为鸿蒙APP做备案
    |
    +-- APP是否联网提供信息服务？
        |
        +-- 否（纯单机离线）→ 路线A: AGC选"单机APP"声明（0元，跳过备案）
        |                     适合: 不联网、无账号、无内购的离线应用
        |                     缺点: 非市场安装可能触发纯净模式提示
        |
        +-- 是（有联网功能）→ 路线B: 正式ICP备案（需ECS+授权码）
                              或: 纯单机APP也可选正式备案以一劳永逸
```

**决策建议**: 纯离线应用如果急着上架走路线A；想一劳永逸或未来计划加联网功能走路线B。

> ⚠️ **游戏类额外要求**：若应用属「游戏」分类（无论单机/联网），上架国内商店通常还需**游戏版号(ISBN)**，且个人无法申请（须企业主体）。详见下方「游戏版号」章节——备案解决的是"互联网信息服务资质"，版号解决的是"游戏出版资质"，两者独立。

## 路线B: 正式备案完整流程

### Step 1: AGC 创建应用（可并行备案）

1. 登录 [AGC控制台](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)
2. 「我的项目」→「添加应用」
3. 关键字段:
   - 选择平台: **APP(HarmonyOS)**（不是Android！）
   - 应用名称: 与备案名称一致
   - 应用包名: 7~128字符，**创建后不可更改**，建议用 `com.公司名.项目名` 格式
   - 应用分类: 工具/教育类选「应用」，不要选「游戏」（游戏需实名认证/防沉迷）
4. 创建后进入应用详情可查看包名（后续备案表单需要）

> 详见 references/form-filling-guide.md 的「AGC应用创建」部分

### Step 2: 购买ECS获取备案授权码

**备案授权码生成条件（硬性要求）**:
- ECS计费模式: **包年/包月**（不是按量/试用）
- 购买时长: **≥3个月**
- 必须绑定**弹性公网IP (EIP)**

**购买要点**:
- 最低配1核1G/2核2G即可（仅用于获取授权码）
- 带宽可降到1Mbps省钱
- IP类型选普通线路即可，不用动态BGP
- 预估花费: 约 ¥120-220（3个月）
- 购买入口: [华为云ECS](https://www.huaweicloud.com/product/ecs.html)

> 免费试用ECS**无法**生成授权码！试用期只有1个月且计费模式不对。

### Step 3: 生成备案授权码

1. 打开 [华为云备案系统](https://beian.huaweicloud.com)
2. 左侧「授权码管理」→「生成授权码」
3. 选择刚购买的ECS实例 + 绑定的EIP → 生成
4. 复制授权码备用

### Step 4: 填写备案表单

**4.1 互联网信息服务类型**: 选 **APP**

**4.2 互联网信息页关键字段**:

| 字段 | 填法 | 踩坑提醒 |
|------|------|---------|
| APP名称 | 与AGC一致 | 不要含「游戏」字样 |
| 首页地址 | 留空（无网站则不填） | 纯APP备案不需要 |
| 服务内容 | 选「教育」或「其他」 | 部分省份「教育」需补充资质 |
| 服务类型 | APP | |
| 语言 | 中文(简体) | 有其他语言可加选 |
| 备注 | 简述功能+强调离线 | 避开「游戏」「在线课程」「社交」等敏感词 |
| APP图标 | 上传，≤100KB | PNG/JPG，需压缩 |

**4.3 接入及平台信息**:

| 字段 | 填法 | 踩坑提醒 |
|------|------|---------|
| 资源类型 | 备案授权码 | |
| 备案授权码 | 粘贴Step 3生成的码 | |
| 域名 | 填ECS公网IP | 没有域名时直接填IP地址 |
| 关联IP | 同上填ECS公网IP | |
| 平台选择 | **只勾「鸿蒙」** | 不要全选！多选其他平台会被要求提供对应证明 |
| 运行平台 | 下拉选「鸿蒙」 | |
| 运行平台类型 | 「移动智能终端」 | |
| 鸿蒙包名 | 从AGC复制 | 与代码bundleName一致 |
| 公钥/签名MD5 | 可先留空试试 | 部分省份不强制，被拒再补 |

> 详见 references/form-filling-guide.md 的「备案表单逐字段指南」

### Step 5: 签名证书与CSR

AGC创建签名证书需要上传CSR文件。两种生成方式:

**方式A: DevEco Studio生成（推荐，100%通过）**
1. DevEco Studio → Build → Generate Key and CSR
2. 填写: Key store path、Password、Key alias、Validity(25年)、姓名/组织/城市/CN
3. 生成 .jks 密钥库 + .csr 文件
4. 在AGC上传.csr → 获取签名证书

**方式B: OpenSSL命令行生成**
```bash
# 生成私钥
openssl genrsa -out private.key 2048
# 生成CSR（需完整字段）
openssl req -new -key private.key -out app.csr -sha256 -utf8 \
  -subj "/C=CN/ST=省份/L=城市/O=组织/OU=部门/CN=姓名/emailAddress=email@example.com"
```
> 注意: OpenSSL生成的CSR可能被AGC拒绝，建议优先用DevEco Studio。

> 详见 references/csr-and-signing.md

### Step 6: 提交备案 → 等待审核

- 提交后状态: 等待初审（1-3工作日）→ 管局审核（~20工作日）
- 收到短信/邮件获得**备案号**

### Step 7: 备案号回填AGC

1. AGC → 应用 → 「核准(备案)信息」模块
2. 填入备案号 + 备案码
3. 完成后续上架流程（图标、截图、简介、隐私政策等）

## 备案完成后可释放ECS

备案号到手后:
- 解绑并释放EIP（IP按带宽持续计费）
- ECS等3个月到期自动释放，不用续费
- 授权码已生效，不依赖服务器存活

## 踩坑清单（必读）

详见 references/pitfalls.md，核心要点:

1. 免费试用ECS拿不到授权码（需包月≥3个月）
2. 平台不要全选，只勾鸿蒙
3. 域名字段没有域名时直接填公网IP（且必须与ECS实际IP一致！）
4. 应用分类选「应用」不选「游戏」；个人开发者服务内容别选「教育」（需前置资质）
5. 包名创建后不可更改，提前想好
6. OpenSSL生成的CSR可能被AGC拒，优先用DevEco Studio
7. APP图标要压缩到100KB以内
8. 备案期间不要改包名和应用名称
9. **备注栏必加承诺话术模板**（缺此话术会被直接驳回，见下方）
10. **通讯地址需与证件住址同省市**（否则要居住证，或改地址）

### ⚠️ 初审驳回高频原因（2026-07 实测）

华为云备案初审已给出 6 类真实驳回理由（详见 pitfalls.md 「初审驳回」完整章节）：

| # | 驳回项 | 一句话修复 |
|---|--------|-----------|
| 1 | 地域不一致 | 通讯地址改回与身份证住址同一省市 / 或上传居住证 |
| 2 | 备注缺承诺话术 | 备注栏追加标准模板（个人使用+虚假备案处罚承诺） |
| 3 | 备注超范围/不详 | 写清用途+具体功能+强调个人使用，不用"平台""社区"等词 |
| 4 | 服务内容涉前置审批 | 个人开发者别选"教育"，改"其他"；有资质则上传证件 |
| 5 | 联系方式重复 | 手机号/邮箱不能与其他备案主体共用，换一个 |
| 6 | IP 与实际不符 | 域名/IP 字段必须 = ECS 实际绑定公网IP，填错必被拒 |

## 游戏版号（游戏类应用必读）

游戏类应用上架国内商店，除备案外还需**游戏版号(ISBN)**，由中宣部/国家新闻出版署核发。**个人无法申请，必须内资企业主体 + ICP证 + 软著**。

**三条路线**：
- **A 正规版号**：注册公司→软著(1-2月)→ICP证(2-3月)→出版社审读→省局→署审批(2-6月)，总周期6-12月，花费2-5万
- **B 规避版号**：商店走「应用」分类（弱化游戏属性），声明单机，0成本即时上架，有被打回风险
- **C 联合出版**：找有版号出版公司分成运营，1-3月

**个人开发者建议**：先B快速验证市场，同时注册公司+启动软著铺路，数据好再补A。
