# AGC 上架常见报错与逐步修复（详细版）

## 0. 单机APP 软著/备案豁免（重要，华为官方客服确认 + 2 个已上架应用佐证）
- **规则**：在 AGC「备案信息」勾选"您的APP为单机APP"，且应用确实不联网（无 INTERNET 权限、无服务器通信）→ **豁免 软件著作权/APP电子版权证书 与 ICP备案/公安备案**。
- **判据**：`grep -rl "INTERNET" entry/src AppScope` 应为空；`module.json5` 不声明 `ohos.permission.INTERNET`。若仍声明 INTERNET，华为提示"识别到联网场景将无法通过审核"，须先去掉权限重构建。
- **错判回顾**：早期误以为"所有中国大陆应用都必须软著+备案"，已被「汉字学习挑战」「割草英雄」无此证过审推翻。**不要再向用户要求单机APP传软著/电子版权。**
- **游戏例外**：游戏大陆发布仍强制版号（见第12节）；单机游戏海外发布连版号/软著都免。

## 1. 图标单层图尺寸不符（最高频）
**审核原文**：应用图标单层图尺寸为 256px*256px（或 512），标准要求尺寸 1024px*1024px。
**根因**：`app_icon.png` 来自旧模板或 AI 生成的 256/512 图，未替换为 1024。
**修复步骤**：
1. 用 ffprobe 确认所有 media 目录的 app_icon/foreground/background/startIcon 尺寸
2. 准备 1024 源图（用户设计稿 / 去白底后的图）
3. 复制到 `AppScope/resources/base/media/app_icon.png` 与 `entry/src/main/resources/base/media/app_icon.png`
4. 同步更新 foreground/background/startIcon 为 1024
5. 备份旧图到 old_icons/，删除 `**/build/**/app_icon.png`
6. DevEco `Build → Build APP(s)` 重新构建
**验证**：rerun check_agc_compliance.sh，全部显示 1024x1024。

## 2. 上传报"离线校验不通过"/无法上传
**根因**：上传的是未签名包，或 Debug 包。
**修复**：Build APP(s) 默认 Release 带签名；或用 DevEco `Build → Upload Product`（云签名，需 Automatically manage signing）。

## 3. KeyAlias not exist
- `KeyAlias (汉字学习挑战) not exist` → 别名填成了应用名，应是密钥库真实别名（如 `hanzi_learn_cert`）
- `KeyAlias {x} not exist in D:/.../hua.p12` → storeFile 路径指错（旧 p12 vs 新 p12）
**修复**：用 keytool 查真实别名与路径；或直接走自动签名绕开。

## 4. keystore password incorrect
**根因**：旧 p12 密码遗忘或填了密文。
**修复**：清空手动三件套，勾选「关联已注册应用」自动签名。

## 5. Profile invalid / expired
**根因**：AGC 后台重新生成了证书/Profile，本地 p7b 过期或不匹配。
**修复**：AGC → 我的应用 → 应用签名 → 重新下载 .p7b 与 .cer，替换本地路径。

## 6. 隐私政策第9项(联系方式)报错
**根因**：只在自定义文本框填了内容，未点「增加商业联系方式」加结构化邮箱/电话。
**修复**：点「增加商业联系方式」，填邮箱(如 <你的邮箱>) 与/或电话。

## 7. 功能异常：闯关/数据不更新（阻断项）
**根因**：结算逻辑未调用存档，或返回页未重新 load 刷新。
**修复核查清单**：
- 结束时是否调用 `saveProgress(context)`
- 是否序列化 levelStars / levelCompleted / totalScore / unlockedLevelIds 到 preferences
- 返回关卡选择页 `aboutToAppear()` 是否 `loadProgress` + `refreshLevels`
若属"故意设计"（如练习不计分），须在 AGC「版本信息 → 应用审核信息」说明设计意图。

## 8. 截图尺寸/比例不符
**根因**：真机全屏截图 1080×2340（9:19.5），AGC 要 1080×1920（9:16）。
**修复**：`ffmpeg -i in.png -vf "crop=1080:1920:0:210" out.png` 中心裁剪；注意中心裁剪可能切到顶部 HUD，可改为顶部起裁 `crop=1080:1920:0:0`。

## 9. 个人开发者 + 游戏 + 鸿蒙激励2026 的死局（最高优先级避坑）
**现象**：个人开发者想用游戏拿鸿蒙激励2026（热门应用 1万/款），发现怎么都上不去。
**根因（三重门槛，环环相扣，已官网核实 2026-08-21）**：
1. 激励仅限"**面向中国大陆**"发布的应用（官网注1）→ **海外发布不参与激励**，两者互斥
2. 个人开发者**无法在中国大陆上架游戏**（需企业资质 + 版号；个人申请不了版号）
3. 游戏只能走"**热门应用**"档（含游戏App），"新应用"档不含游戏；且热门应用需"用户基础或社会/行业影响力（如 App Store 推荐）"
→ 结论：个人开发者**实际拿不到游戏激励**。这不是 Bug，是规则设计。
**正确路径**：
- 想拿激励 → 做**非游戏应用**走"**新应用**"档（3000元/款），个人可参与（官网 Q15：个人报名公司信息填"姓名"或"无"即可）
- 新应用达标条件：面向中国大陆上架 + 任一自然月有效月活≥400 + 用户评分>3 且评分数≥10 + 2026-9-30 前首次上架 + 报名(9-25前) + 开通商户服务(9-30前) + 不主动下架至 2026-12-31
- 游戏若只给用户玩 → 可**海外发布**（免版号/软著/备案，个人可发，开发者论坛实测成功），但拿不到激励
- 变现注意：鲸鸿动能广告(IAA)/IAP 内购需企业资质；**个人应用务必"无广告 + 无内购"**，否则触发企业要求、且个人开不了广告位
- 设备范围：激励仅限手机/平板/PC（手表除外）

## 10. 隐私政策 HTTPS 托管（2026 强制必填）
**现象**：2026 年起所有上架应用必填"隐私政策网址"（HTTPS 链接），否则无法提交审核。
**坑**：自租 ECS（如 1.95.77.60）22/80/443/8888 端口全不通，网页打不开。
**正确方案**：改用**华为云 OBS 对象存储**建"公共读"桶 → 上传 `privacy_policy.html` → 复制对象 URL（天然 HTTPS，形如 `https://{桶名}.obs.{区域}.myhuaweicloud.com/privacy_policy.html`）。次选 GitHub Pages。
**内容必备**：基本功能服务说明 + 用户权利（查阅/复制/删除/撤销同意/投诉 ≤15 工作日）+ 双清单（个人信息收集清单 + 权限清单，无则填空）。
**AGC 填法**：版本信息页"隐私政策网址"框粘贴 URL（带 * 必填）；"隐私权利"框无 * 可不填。

## 11. 应用名被占 / 包名唯一
**现象**：建应用时提示名称已被使用。
**修复**：展示名可改（如"割草英雄"→"割草英雄MowHero"），但 **bundleName(包名) 全网唯一不可改**，建应用时一次性定死（如 com.pulsestudio.survivor）。改名不影响包名。

## 12. 单机游戏中国大陆发布仍强制版号
**现象**：以为"单机+不联网+无内购"可豁免版号。
**核实**：华为应用市场明确——无论单机/网游、有无内购，中国大陆发布游戏**均需版号**（ISBN）。仅"海外发布"可免。且个人申请不了版号（需企业主体）。
