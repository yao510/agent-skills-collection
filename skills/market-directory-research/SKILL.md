# 公开市场商户/企业名录调研与交付

## 适用场景
用户要求汇编某个具体市场、商圈、产业园、建材城等的商户/企业信息（公司名、行业、法人、电话、邮箱、官网、成立年份、注册资金等），并要分类 Excel、分布图、发展规划、政策动向。

## 关键前置判断（务必先做）
1. **数据接口**：先确认企查查/天眼查等工商数据连接器是否连接。本环境常处于"未连接"，只能走公开网络资料。
2. **隐私边界**：法人个人手机号、私人邮箱属敏感个人信息，全量采集不可靠且不合规。只收录企业**公开披露**的商务联系方式（公司座机/官网/公开电话）；在交付物与说明中明确此边界。
3. **"所有商户"体量**：真实市场动辄数千家，公开网络只能拿到样本。必须向用户说明这是"公开可查样本"，非全量工商底档，并标注商户数统计口径不可直接相加。

## 工作流
1. **澄清范围**（AskUserQuestion 一次问清：具体对象 / 数据来源 / 交付深度 / 隐私边界）。
2. **并行研究代理**：启动 2 个 general-purpose 代理（run_in_background=true）——
   - 代理A：市场生态（各商城/分店/工业区/物流区）、发展规划、政策动向、周边小区人口，返回结构化 markdown + 来源URL。
   - 代理B：公开商户/企业名录 + 外贸公司，返回 markdown 表格（列：公司名|品类|位置|法人|电话|邮箱|官网|成立年份|注册资本|来源），**严禁虚构**联系方式，未知留空。
3. **落盘原始数据**：将代理返回的 markdown 表格写入 `raw_directory.md`（含「商户名录」「外贸公司」两个 `## ` 小节）。
4. **解析+建 Excel**（openpyxl）：
   - 解析 markdown 表格 → 用分类函数把每个商户归到「商城/工业区」和「品类大类」。
   - 生成多 Sheet：说明与数据来源 / 商户总表 / 按商城分类（汇总+明细）/ 外贸公司 / 商城与工业区 / 发展规划 / 政策动向 / 周边小区人口 / 数据来源清单。
   - 表头蓝色填充、冻结首行、自动筛选、列宽、自动换行。
5. **可视化 HTML**（内嵌 SVG）：商城与工业区分布示意图（上北下南，纵轴=主干道、横轴=环线，框内标注公开商户数）、品类横向条形图、发展规划时间线（近年-中期-远期）、政策卡片、小区人口表。浅色主题。
6. **导出 stats.json**（zone_counts / cat_counts / zone_merchants）供 HTML 复用。

## 环境坑（本机 Windows）
- Python venv 路径是 `<你的venv python路径>`（**Scripts 不是 bin**），pip 用 `Scripts/pip.exe`。
- 安装包：`Scripts/pip.exe install openpyxl`。

## 解析 markdown 表格要点
- 按 `## ` 分节；表格行以 `|` 开头；首行表头，含 `---` 的为分隔行跳过。
- 单元格用 `|` 分隔，先 `strip("|")` 再 split。

## 交付后
- present_files 同时给出 .xlsx 与 .html。
- 写入项目 memory 记录事实与口径；重复执行同类任务可复用本技能。
