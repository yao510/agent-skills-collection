---

## 1. WorkBuddy（已装，无需操作）
技能位于 `~/.workbuddy/skills/ironclad-delivery/`，用户级全局默认生效。说"证据呢/验收/换个方法/别摆烂/端到端"会强制启动压力模式。

## 2. deepseek-harness（已装，可回滚）
- 协议文件：`D:\deepseek-harness\IRONCLAD_RULES.md`
- 注入点：`D:\deepseek-harness\dsh-chat.js`（启动时把协议作为系统简报发给 AI；`/new` 新会话会自动重注入）
- 回滚：把 `dsh-chat.js.bak` 复制回 `dsh-chat.js` 即可恢复原始版

## 3. TraeCode CN
- 入口：左下角 **设置（齿轮） → 规则 (Rules) → 用户规则 (User Rules)** → 粘贴全文 → 保存
- 备选（项目级）：在你项目的根目录新建 `.trae/rules/ironclad.mdc`，内容填协议全文
- 效果：该工具所有对话默认遵守

## 4. Qoder IDE
- 入口：左下角 **设置 → 规则 / Rules → 用户规则** → 粘贴全文 → 保存
- 备选（项目级，推荐）：在项目根目录新建 `AGENTS.md`，把协议全文贴进去，Qoder 会自动读取
- 也可放：`项目/.qoder/rules/ironclad.mdc`

## 5. DevEco Studio（HarmonyOS/ArkTS 开发）
- 入口：**设置 (Settings) → 鸿蒙开发 / CodeArts / AI 辅助编程 → 自定义指令 / 系统提示词** → 粘贴全文 → 应用
- 备选（项目级）：项目根目录放 `AGENTS.md` 填入协议全文
- 注意：不同 DevEco 版本菜单名称略有差异，关键词是"自定义指令 / 规则 / 系统提示词"，看到任意一个就对了

## 6. CodeArts Agent（华为云）
- 入口：**设置 → 智能助手 / CodeArts → 个人偏好 / 自定义指令** → 粘贴全文 → 保存
- 重要：你 `memory/D--YAO/` 里已有 `anti_lazy_persistence.md`、`anti_lazy_skill_system.md` 等防偷懒规则——**建议用本统一版替换/合并**，避免多套规则打架。直接把 `铁血交付协议_通用指令.md` 全文粘进自定义指令即可覆盖旧规则的精神。

## 7. OfficeAce（WPS）
- 入口：打开 OfficeAce → **设置 / 偏好 → AI 助手 / 自定义指令 / 系统提示词** → 粘贴全文 → 保存
- 关键词同样是"自定义指令 / 系统提示词"，找到对应框粘贴即可

---

## 通用兜底方案（适用于任何工具）
如果找不到上面的菜单，用这个**万能法**：
1. 打开 `铁血交付协议_通用指令.md` → 全选复制
2. 在你用的工具里找任意一个"自定义指令 / 系统提示词 / Rules / 个人偏好"输入框（通常在设置里）
3. 粘贴 → 保存
4. 新开一个对话，发一句"请复述你的工作纪律"验证它是否已加载协议

## 红线提醒（对所有工具一致）
协议只管**执行严谨度**（收据、升级、不甩锅），**不替代你的工艺/方向/分模决策**。若某工具把"自定义指令"当成了"替你定方案"，那是误用，记得它只是纪律约束。
